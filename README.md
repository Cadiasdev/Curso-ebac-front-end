<strong>Formulário de Cadastro</strong>

Este projeto consiste em um formulário de contato 
responsivo e estilizado utilizando Bootstrap 5 e 
CSS personalizado. O formulário é projetado para 
ser simples, elegante e fácil de usar, permitindo 
que os usuários entrem em contato com a empresa.

<strong>Funcionalidades</strong>

- Formulário de entrada de dados com campos para nome, e-mail, telefone e mensagem.
- Campo de confirmação de termos de política.
- Estilo responsivo que se adapta a diferentes tamanhos de tela.
- Design moderno com fundo semitransparente, bordas arredondadas e sombra suave.

<strong>Tecnologias Utilizadas</strong>

- **HTML**: Estruturação do conteúdo da página.
- **CSS**: Estilização personalizada para tornar o formulário atraente.
- **Bootstrap 5**: Framework CSS para garantir a responsividade e facilitar o layout.
